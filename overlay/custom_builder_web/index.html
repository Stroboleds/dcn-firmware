Dual-Cell-Net EU 868 MHz Build en la nube

Dos celdas mesh. Una antena. Tu firmware.

Cell-Mesh (DCN) empaqueta la pila dual-mesh (Meshtastic + MeshCore en SX126x) con marca y canales europeos. Cada operador genera su binario desde el navegador; la compilación ocurre en GitHub Actions, no en tu PC.

Generar mi firmware Instalar / actualizar

Builder comunitario

Elige placa (p. ej. T-Deck TFT), región, canales y nombre de nodo. El workflow custom_builder.yml produce un zip listo para flashear.

Flasher en el navegador

Instala por USB con Chrome/Edge (ESP32) o arrastra UF2 (nRF52). Incluye OTA loader cuando corresponde.

Documentación heredada

Los manuales de comandos Nexus y dual-mesh siguen en docs/ (adaptados desde upstream). La portada DCN es distinta; el motor técnico es compatible.

En tres pasos

  1. Abre el generador, configura equipo y preferencias (incluido tema de pantalla si tu placa lo muestra).
  2. Autoriza GitHub Actions y descarga el artefacto cuando termine el job.
  3. Flashea con flasher o el script del bundle.

Temas y color en el dispositivo

Los temas de color (azul eléctrico, teal DCN, naranja, violeta, etc.) afectan la interfaz del nodo (pantalla TFT / mapa), no esta web. En el builder, elige el tema en las opciones de UI del equipo; queda sellado en userPrefs del firmware.
